# SMARTSHIELD – Intrusion Detection and Prevention System (IDS/IPS)

## Project Overview

SmartShield is a web-based Intrusion Detection and Prevention System (IDS/IPS) developed as a Cyber Security project. It provides a platform for monitoring security-related events and viewing system statistics through a web dashboard.

The application is developed using Python Flask, SQLite, HTML, CSS and JavaScript.

## Objectives

- Develop a web-based security monitoring application.
- Monitor and display security events.
- Provide statistics through dashboard visualizations.
- Maintain event information using an SQLite database.
- Deploy the application online for remote access.

## Installation and Execution

### 1. Clone the repository

```bash
git clone https://github.com/mrkarthik109/IDS-IPS.git
```

### 2. Navigate to the project directory

```bash
cd IDS-IPS
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the environment

Windows:

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

### 7. Open in browser

```text
http://127.0.0.1:5000
```
